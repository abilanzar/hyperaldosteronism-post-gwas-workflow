# Public-release boundary

This repository contains only synthetic inputs and outputs created for a technical portfolio.

## Intentionally excluded

- Participant-level genotype, phenotype, covariate, and electronic-health-record data
- Controlled-access biobank files and credentials
- Unpublished project summary statistics and locus-level effect estimates
- Manuscript tables, figures, draft text, and collaborator materials
- Real FUMA, MESuSiE, LDSC, MR, PRS, PheWAS, TWAS, colocalization, MAGMA, or PoPS outputs
- Private filesystem paths, cluster names, job identifiers, account names, and API tokens

## What the repository demonstrates

- Explicit input schemas and validation
- Genome-build and allele-awareness
- Locus bookkeeping and credible-set auditing
- MR allele harmonization and sensitivity diagnostics
- PRS model comparison and PheWAS multiplicity correction
- Evidence integration with conservative claim ceilings
- Reproducible execution and automated release gates

The synthetic values are fictional and cannot be used to infer the unpublished study's findings.
